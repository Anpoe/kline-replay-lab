# KLine Replay Lab / K线训练营 2.0

一个本地优先的多市场 K 线回放与交易训练工具。当前重点支持 A 股、美股样例行情，提供逐根 Replay、模拟交易、多仓位管理、图表标记和结构化复盘。

## 当前能力

- 5 分钟、1 小时、日线和周线 K 线。
- 隐藏未来、随机起点、逐根推进、倍速播放。
- 趋势线、水平线、通道、斐波那契和自由标记。
- 下一根 K 线开盘成交的模拟市价单。
- 多笔独立多头/空头仓位、逐笔平仓和订单列表。
- A 股主板普通股票基础规则：禁止做空、买入 100 股整手、T+1、10% 涨跌幅，以及涨跌停无盘口时的保守成交处理。
- 图表买入、卖出、平仓点及开平仓虚线；默认半透明、悬停增强。
- 事前决策卡可冻结为绑定原始K线的计划记录；盘面标记、当前复盘和历史复盘均可查看完整内容。
- 训练自动保存、关闭网页后自动续训、历史训练直接查看/重开和结构化复盘。
- 内容哈希不可变行情快照，可在原行情库被更新后完整恢复训练使用的 K 线版本。
- 按顺序保存推进、下单、成交、正式决策提交、绘图和播放操作的事件日志；草稿输入不会按字符污染审计记录，历史训练支持确认删除。
- CSV OHLCV 导入和数据库覆盖页面。

## 本地启动

Windows 用户可直接双击：

```text
启动本地网页版.bat
```

启动后打开：

```text
http://localhost:3000
```

也可以使用命令行：

```powershell
cd web
npm install
npm run dev
```

需要 Node.js 22.13 或更高版本。

## 当前阶段

这是本地纵向原型，尚未接入正式行情供应商。新建训练已绑定内容寻址的不可变行情快照和版本化市场规则，可跨行情数据版本恢复；升级前创建的旧训练会在首次恢复时基于当前行情补建快照，无法反向找回升级前已被改写的数据。当前市场规则只覆盖 A 股主板普通股票的基础边界；真实 A 股/美股历史数据、其他板块与特殊证券规则、确定性统计和 AI 策略总结仍在开发计划中。

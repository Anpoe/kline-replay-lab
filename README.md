# KLine Replay Lab / K线训练营 2.0

一个本地优先的多市场 K 线回放与交易训练工具。当前已接入 A 股、美股和外汇数据链路，并保留 A 股/美股内置样例；提供逐根 Replay、模拟交易、多仓位管理、图表标记和结构化复盘。黄金仍只有独立管理入口，尚未接入正式数据与成交规则。

## 当前能力

- 1 分钟、5 分钟、1 小时、日线和周线 K 线；具体可选范围按品种已入库覆盖决定。
- 隐藏未来、随机起点、逐根推进、倍速播放。
- 可按日期或第 N 根 K 线开始，设置揭示长度并在边界自动结束。
- 支持自由训练、盲测、固定测试区间和基于低分计划/规则拒单的错题重练。
- 顶部提供独立“随机训练”入口，可选择普通随机或盲测随机；每局结束后的“继续随机”会完整沿用品种池、周期、日期、长度、盲测和形态筛选配置，也可查看复盘或退出随机训练。
- 手机端周期面板提供“一键随机训练形态”选择；选择会保存在本机，之后点击随机按钮会直接按上次形态筛选历史训练位置。
- 形态筛选内置“上升趋势”和“上升趋势突破”：前者检查价格/短均线/长均线的多头排列及长均线斜率，后者在此基础上继续要求当前收盘突破此前区间高点；阈值与成交量确认均可自定义。
- 顶部“实盘筛选”入口位于随机训练左侧：第一版支持 A 股与美股日线，只判断最近一个完整收盘交易日。确认后先自动执行 Tushare A 股增量或 Alpaca 美股 SIP 增量，再按形态、收盘价和 20 日平均成交量筛选；结果可按成交额、成交量或当日涨幅排序并直接打开最新图表。美股历史当前坚持 SIP-only，账户无 SIP 权限时会明确报错，不静默回退到只覆盖部分成交场所的 IEX。
- 训练中可独立隐藏品种名称、日期坐标和绝对价格；盲测完成前锁定复盘答案。
- 趋势线、水平线、通道、斐波那契、矩形、箭头、文字和自由画笔；支持磁吸、样式调整、锁定、显隐、删除、撤销/重做和对象树，并随训练保存恢复。
- `2026.08-v4` 版本化确定性成交引擎：市价单在下一根开盘成交，限价单与止损触发单会跨 K 线等待；支持跳空价格、自动止损/止盈、手续费、最低佣金、点差、滑点、按单根 K 线成交量参与率部分成交，以及同根 K 线止损/止盈冲突的保守、乐观或种子确定规则。未成交余量保留为原委托继续等待；外汇成交额外支持 Bid/Ask 方向、手数/合约/点值/币种换算及保证金强平。
- 下单可选固定数量或账户权益风险百分比；风险仓位按止损距离反算数量，并计入点差、滑点、入场与预估出场佣金，再按市场最小数量/增量和资金购买力向下取整。
- 止损和止盈改为点击图表取价；计划保护线直接显示在图表上。持仓建立后可像 MT4/MT5 一样拖动止损线收紧风险，非法的放宽止损或穿越当前价会被拒绝。保护价与事前决策卡双向联动；即使未填写其他字段，取价时也会自动生成绑定当前 K 线的保护计划记录，继续选择另一保护价会更新同一张自动卡，之后正式提交完整计划会替换它。
- 多笔独立多头/空头仓位、逐笔平仓和订单列表。
- A 股主板、科创板、创业板与北交所普通股票基础规则：禁止做空、板块对应的最低买入数量与增量、T+1、10%/20%/30% 涨跌幅、IPO 初期无涨跌幅天数，以及涨跌停无盘口时的保守成交处理。
- 图表买入、卖出、平仓点及开平仓虚线；默认半透明、悬停增强。
- 事前决策卡可冻结为绑定原始K线的计划记录；盘面标记、当前复盘和历史复盘均可查看完整内容。
- 训练仅在手动点击“保存训练”或到达训练终点时建立保存点；历史训练可直接查看、继续、删除和结构化复盘。
- 侧栏设置包含基本设置与训练设置，可配置独立随机训练入口使用的品种池、指定市场、随机/固定周期、历史时间段和默认训练长度。市场专用限制只在随机范围可能抽到该市场时出现：A 股显示指数范围，美股显示流动性门槛，指定 FX 等其他市场时不显示无关选项。随机训练默认只抽取当前已开放模拟交易的品种，也可显式纳入指数进行只看盘训练；美股默认排除 Rights/Warrants/Units，并要求训练起点前 20 个交易日平均成交额不少于 100 万美元，门槛可关闭或调整且不会删除原始行情和快照。
- 可恢复训练卡清楚显示训练模式、状态、日期范围、进度、总盈亏、已实现/浮动盈亏和持仓数量。
- 独立“表现”板块默认分析全部已保存训练，筛选器置顶并可按品种、周期、模式、形态、状态和日期缩小训练集；同时分析最优持仓时长、市场状态、位置、交易理由、计划习惯、实际命中形态、开仓价格区间、开仓前 20 日平均成交量/成交额及其组合，单笔样本不会直接标为最优。市值区间已预留给证券基础资料，K 线本身无法可靠推算市值。正式事前计划优先，旧版补写计划在没有正式计划时作为兼容样本并显示来源数量；训练明细的复盘/继续入口位于每行右侧，桌面悬停显示、手机常显。
- 基本设置、训练设置、形态预设、随机方式与随机形态、MA/EMA、自定义理由标签和绘图偏好会写入同一份本机数据库设置；电脑与手机连接同一台本地服务时，在重新打开页面或回到前台后同步，不再受 `localhost` 与局域网地址的浏览器存储隔离影响。
- 交易胜率按“胜 ÷ (胜 + 负)”计算，训练胜率也按“训练胜 ÷ (训练胜 + 训练负)”计算；平局单独展示但不计入胜负分母。
- 单场复盘保存确定性指标快照：逐笔净/毛盈亏与费用、初始风险 R、MFE/MAE、出场效率、入场后 1/3/5/10 根路径、期望值、盈亏比、Profit Factor、逐 K 权益最大回撤、水下时长和最大连亏；MFE/MAE 与回撤保留证据时间点，缺失旧行情时明确标记而不估算。
- 图表默认缩放分别针对电脑和手机优化；用户手动缩放后，逐根推进和新开一局都会保持当前密度，仅刷新网页时重新应用默认缩放。
- v2 内容哈希不可变行情快照：按周期分桶、按大小拆分并复用相同内容块；恢复训练时按原任务区间加 100～5000 根可配置左侧历史窗口读取，旧 v1 完整/差异链快照继续兼容。
- 按顺序保存推进、下单、成交、正式决策提交、绘图和播放操作的事件日志；草稿输入不会按字符污染审计记录，历史训练支持确认删除。
- CSV OHLCV 导入和数据库覆盖页面。
- 数据页首次打开提供“快速初始化”和“高级自定义”：推荐方案会实际下载通达信官方沪深京日线完整包，支持断点续传、ZIP 校验、证券分类、分区索引和周线按需生成；高级方案可组合 Tushare、TdxQuant、Alpaca 和本地文件。
- 数据管理按 A股、美股、外汇、黄金独立切换；不再手工逐个输入证券代码。A股用 TDX 完整包建立全历史基础库，之后用 Tushare 120 做普通股票不复权日线的每日增量和最近 30 日缺口修复；美股使用 Alpaca SIP 并按证券目录限速更新，权限不足时保留清晰错误，避免同一历史序列混入定义不同的 IEX 数据。
- A 股增量只保存新增或修正的 K 线，并在读取时与 TDX 全历史合并；维护任务可暂停、恢复和失败重试，Token 不写入任务文件。TdxQuant 本地端点可在设置中保存，完整分钟线连接器仍在后续数据闭环中。

## 本地启动

Windows 用户可直接双击：

```text
启动本地网页版.bat
```

启动后打开：

```text
http://localhost:3000
```

启动窗口还会显示局域网手机地址和已配置的 dynv6 远程地址：

```text
http://kline42.dynv6.net:3000
```

远程地址依赖 DDNS-GO 将该域名的 AAAA 记录更新为本机公网 IPv6，并需要在 Windows 与路由器 IPv6 防火墙中明确允许 TCP 3000。启动脚本不会自动开放公网端口。当前本地版没有公网账号体系，建议只在个人使用时临时开放；长期开放前应增加 HTTPS 和访问认证。

脚本会同时在 `127.0.0.1:3100` 启动只供本机使用的数据服务。大约 520 MB 的完整包下载和 `.day` 解析由它处理，不会把整个文件塞进浏览器内存；进度保存在 `web/.local-data/`，关闭网页后仍可继续。

也可以使用命令行：

```powershell
cd web
npm install
npm run local-data
```

另开一个终端：

```powershell
cd web
npm run dev
```

需要 Node.js 22.13 或更高版本。

## 配置真实行情

启动本地网页版后，打开侧栏“设置 → 数据源设置”，直接填写并保存：

- Alpaca API Key ID 和 Secret Key：用于美股。
- Tushare Token：用于 A 股。
- Twelve Data API Key：用于外汇已收盘 M1 增量；Dukascopy 历史初始化使用内置官方适配器，无需填写地址。
- TdxQuant 本地端点：用于以后接入已启动的通达信 TQ 客户端，默认 `http://127.0.0.1:17709`。

凭证只保存在这台电脑的本地数据库，界面不会回显完整内容，也不会进入 Git。保存后无需重启；A 股完成 TDX 初始化后即可使用 Tushare 120 的每日增量和缺口修复。外汇增量只向 Twelve Data 请求 1min，保存 M1 后由本地生成 5m/1h/1d/1w。Tushare 的 5m/1h 历史分钟线仍取决于更高的数据权限。

`web/.env.local` 仍可作为高级兼容配置，但普通使用不再需要手动编辑文件。

## 当前阶段

这是本地纵向原型。通达信全市场日线完整包已接入本机断点下载和文件分区仓库；训练、随机训练、覆盖统计与不可变快照会通过统一行情接口读取日线，周线按自然交易周聚合。证券类型由代码规则自动识别，导入完成后会同步在线中文证券目录；无法匹配的少量历史代码仍显示确定性占位名，也可用 `web/.local-data/catalog.json` 补充映射。数据库覆盖表可勾选删除样例或正式行情，删除行情不会删除已有训练快照。指数在品种选择器和训练顶部显示为“指数”，仅用于回看、标记与决策训练，交易区会明确提示不可直接交易。快照已经升级为内容寻址分块和范围读取，但创建首份快照时仍会加载完整序列，引用管理与未引用块回收还没做。成交引擎已升级到 `2026.08-v4`：部分成交、权益风险百分比仓位、图表保护价选取与移动止损已形成首版闭环；外汇新增基于 BID K 线和冻结点差的 Bid/Ask 方向语义、0.01 手数量、10 万基础币合约、Pip/Point 价值、基础币/报价币自动换算及第三币种固定汇率，并完成杠杆、占用/可用保证金、保证金水平和逐 K 强平。仍缺用户指定的分批退出/分批止盈、固定金额风险、外汇交易周和隔夜费。当前 P0 缺口是其余市场专用成交细则、跨训练确定性指标聚合与证据跳转、事件重放/迁移、全历史数据质量扫描和高周期未来隔离。详细验收清单见方案文档第 13.6 节。

# KLine Replay Lab / K线训练营 2.0

一个本地优先的多市场 K 线回放与交易训练工具。当前重点支持 A 股、美股样例行情，提供逐根 Replay、模拟交易、多仓位管理、图表标记和结构化复盘。

## 当前能力

- 5 分钟、1 小时、日线和周线 K 线。
- 隐藏未来、随机起点、逐根推进、倍速播放。
- 趋势线、水平线、通道、斐波那契和自由标记。
- 下一根 K 线开盘成交的模拟市价单。
- 多笔独立多头/空头仓位、逐笔平仓和订单列表。
- 图表买入、卖出、平仓点及开平仓虚线；默认半透明、悬停增强。
- 事前决策卡、本地训练保存、基础复盘。
- CSV OHLCV 导入和数据库覆盖页面。

## 本地启动

Windows 用户可直接双击：

```text
启动本地网页版.bat
```

启动后打开：

```text
http://localhost:3000
```

也可以使用命令行：

```powershell
cd web
npm install
npm run dev
```

需要 Node.js 22.13 或更高版本。

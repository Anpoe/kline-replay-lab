# KLine Replay Lab / K线训练营 2.0

一个本地优先的多市场 K 线回放与交易训练工具。当前重点支持 A 股、美股样例行情，提供逐根 Replay、模拟交易、多仓位管理、图表标记和结构化复盘。

## 当前能力

- 5 分钟、1 小时、日线和周线 K 线。
- 隐藏未来、随机起点、逐根推进、倍速播放。
- 可按日期或第 N 根 K 线开始，设置揭示长度并在边界自动结束。
- 支持自由训练、盲测、固定测试区间和基于低分计划/规则拒单的错题重练。
- 顶部提供独立“随机训练”入口，可选择普通随机或盲测随机；每局结束后可继续随机、查看复盘或退出随机训练。
- 训练中可独立隐藏品种名称、日期坐标和绝对价格；盲测完成前锁定复盘答案。
- 趋势线、水平线、通道、斐波那契和自由标记。
- 下一根 K 线开盘成交的模拟市价单。
- 多笔独立多头/空头仓位、逐笔平仓和订单列表。
- A 股主板普通股票基础规则：禁止做空、买入 100 股整手、T+1、10% 涨跌幅，以及涨跌停无盘口时的保守成交处理。
- 图表买入、卖出、平仓点及开平仓虚线；默认半透明、悬停增强。
- 事前决策卡可冻结为绑定原始K线的计划记录；盘面标记、当前复盘和历史复盘均可查看完整内容。
- 训练仅在手动点击“保存训练”或到达训练终点时建立保存点；历史训练可直接查看、继续、删除和结构化复盘。
- 侧栏设置包含基本设置与训练设置，可配置独立随机训练入口使用的品种池、指定市场、随机/固定周期、历史时间段和默认训练长度。
- 可恢复训练卡清楚显示训练模式、状态、日期范围、进度、总盈亏、已实现/浮动盈亏和持仓数量。
- 独立“表现”板块汇总全部已保存训练，并可按品种、周期、模式、状态和日期筛选训练集；选中单次训练后可查看复盘或继续训练。
- 内容哈希不可变行情快照；首版保存完整数据，后续版本只保存新增、修正和删除差异，可在原行情库更新后完整恢复且不会重复复制整套行情。
- 按顺序保存推进、下单、成交、正式决策提交、绘图和播放操作的事件日志；草稿输入不会按字符污染审计记录，历史训练支持确认删除。
- CSV OHLCV 导入和数据库覆盖页面。
- 数据页首次打开提供“快速初始化”和“高级自定义”：推荐方案会实际下载通达信官方沪深京日线完整包，支持断点续传、ZIP 校验、证券分类、分区索引和周线按需生成；高级方案可组合 Tushare、TdxQuant、Alpaca 和本地文件。
- 数据管理按 A股、美股、外汇、黄金独立切换；不再手工逐个输入证券代码。A股用 TDX 完整包建立全历史基础库，之后用 Tushare 120 做普通股票不复权日线的每日增量和最近 30 日缺口修复；美股可用 Alpaca 免费 IEX 行情按证券目录批量初始化并限速更新。
- A 股增量只保存新增或修正的 K 线，并在读取时与 TDX 全历史合并；维护任务可暂停、恢复和失败重试，Token 不写入任务文件。TdxQuant 本地端点可在设置中保存，完整分钟线连接器仍在后续数据闭环中。

## 本地启动

Windows 用户可直接双击：

```text
启动本地网页版.bat
```

启动后打开：

```text
http://localhost:3000
```

启动窗口还会显示局域网手机地址和已配置的 dynv6 远程地址：

```text
http://kline42.dynv6.net:3000
```

远程地址依赖 DDNS-GO 将该域名的 AAAA 记录更新为本机公网 IPv6，并需要在 Windows 与路由器 IPv6 防火墙中明确允许 TCP 3000。启动脚本不会自动开放公网端口。当前本地版没有公网账号体系，建议只在个人使用时临时开放；长期开放前应增加 HTTPS 和访问认证。

脚本会同时在 `127.0.0.1:3100` 启动只供本机使用的数据服务。大约 520 MB 的完整包下载和 `.day` 解析由它处理，不会把整个文件塞进浏览器内存；进度保存在 `web/.local-data/`，关闭网页后仍可继续。

也可以使用命令行：

```powershell
cd web
npm install
npm run local-data
```

另开一个终端：

```powershell
cd web
npm run dev
```

需要 Node.js 22.13 或更高版本。

## 配置真实行情

启动本地网页版后，打开侧栏“设置 → 数据源设置”，直接填写并保存：

- Alpaca API Key ID 和 Secret Key：用于美股。
- Tushare Token：用于 A 股。
- TdxQuant 本地端点：用于以后接入已启动的通达信 TQ 客户端，默认 `http://127.0.0.1:17709`。

凭证只保存在这台电脑的本地数据库，界面不会回显完整内容，也不会进入 Git。保存后无需重启；A 股完成 TDX 初始化后即可使用 Tushare 120 的每日增量和缺口修复。5m/1h 历史分钟线仍取决于更高的数据权限。

`web/.env.local` 仍可作为高级兼容配置，但普通使用不再需要手动编辑文件。

## 当前阶段

这是本地纵向原型。通达信全市场日线完整包已接入本机断点下载和文件分区仓库；训练、随机训练、覆盖统计与不可变快照会通过统一行情接口读取日线，周线按自然交易周聚合。证券类型由代码规则自动识别，导入完成后会同步在线中文证券目录；无法匹配的少量历史代码仍显示确定性占位名，也可用 `web/.local-data/catalog.json` 补充映射。数据库覆盖表可勾选删除样例或正式行情，删除行情不会删除已有训练快照。交易日历缺口扫描和自动增量更新仍待补充。当前市场规则只覆盖 A 股主板普通股票的基础边界；其他板块与特殊证券规则、确定性统计和 AI 策略总结仍在开发计划中。

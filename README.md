# K 线训练营 2.0

一个在 Windows 本机运行的 K 线回放、模拟交易与复盘工具。它适合用来练习看盘、验证交易规则，以及在不承担真实资金风险的情况下复盘交易过程。

当前版本支持 A 股、美股、外汇和现货黄金相关训练场景，并提供示例数据、逐根回放、模拟下单、仓位管理和训练记录功能。

> 当前版本：`v0.1.6`<br>
> [下载最新版本（GitHub Releases）](https://github.com/Anpoe/kline-replay-lab/releases/latest)

## 给普通用户：三分钟开始使用

### 1. 下载并解压

在 [Releases](https://github.com/Anpoe/kline-replay-lab/releases) 页面下载 Windows 便携版压缩包：

`KLineTrainingCamp-Portable-v0.1.6.zip`

请将压缩包完整解压到一个独立文件夹后再运行。建议使用你有读写权限的目录，例如：

`D:\Apps\KLineTrainingCamp`

不要直接在压缩包内部运行，也不要只把 `.exe` 单独复制出来；程序需要和同目录下的运行文件、`web` 文件夹一起工作。

### 2. 启动控制面板

双击：

`KLineTrainingCamp.ControlPanel.exe`

打开控制面板后点击“启动服务”。当“本地数据服务”“WebUI”“后台更新任务”都显示为“就绪”时，点击“打开 WebUI”。

关闭控制面板窗口只会隐藏到系统托盘；需要停止服务时，请从托盘菜单选择“退出”。

启用开机后台启动后，程序会在 Windows 登录时自动启动并在后台检查更新；同一天不会重复执行。

也可以在浏览器中打开：

<http://localhost:3101>

便携版已经包含程序核心运行组件，普通用户不需要另外安装开发工具。需要接入外部行情时，请按“数据”页面的连接引导完成数据服务准备。

### 3. 第一次使用

首次打开后可以直接使用内置示例数据练习，不需要先填写行情接口密钥。建议按这个顺序熟悉程序：

1. 进入训练页面，选择市场、品种和周期。
2. 点击开始回放，使用逐根推进观察行情。
3. 根据当前训练模式进行模拟买卖、设置止损止盈并管理仓位。
4. 在训练结束后查看订单、持仓、资金曲线和复盘信息。

如果需要完整的 A 股历史数据，请先在“数据”页面确认数据服务状态，再执行快速初始化。首次初始化会下载较大的数据包，过程可能需要几分钟，并会占用额外磁盘空间；下载过程中请保持应用打开。

需要接入真实行情时，按以下路径操作：

1. 打开“设置 → 数据源设置”，选择需要的数据服务并保存连接信息。
2. 返回“数据”页面，选择市场、品种和历史范围，开始建立训练数据。
3. 根据页面显示的连接状态和任务进度继续操作；连接失败或数据为空时，按页面提供的设置、重试或返回入口处理。

## 程序包含什么

- K 线逐根回放和训练进度控制
- 模拟下单、订单状态、持仓和资金变化
- 收益率模式、资金账户模式等训练方式
- 固定数量、按风险比例等下单方式
- 止损止盈、滑点、手续费和成交限制模拟
- 图表标记、训练记录和复盘
- A 股、美股、外汇、现货黄金训练入口
- 示例数据与可选的外部行情数据源

这是训练和模拟工具，不会替代券商交易终端，也不会自动执行真实交易。请在使用真实行情接口时确认服务商的授权范围和使用限制。

## 设置、个人数据和默认值

### 哪些是默认设置

新用户第一次打开程序时看到的设置来自程序内置默认值，例如默认品种、周期、下单数量、账户模式、手续费和滑点。它们只是起始值，不代表某个用户的个人设置。

在设置页面修改并保存后，新的训练会使用你保存的值。已经创建的训练通常会继续使用创建时记录的训练参数，不会因为后来切换全局设置而被悄悄改写。

### 为什么有些设置保存在浏览器里

少量即时界面偏好仍属于“浏览器个人覆盖值”，例如面板展开状态、随机训练模式、数据初始化向导方案、最近看盘结果、移动平均线显示和最近一次训练保存点。它们保存在当前电脑、当前浏览器、当前地址的浏览器本地存储中，不会上传到 GitHub，也不会自动同步到其他电脑。

交易理由标签和自定义形态预设已经改为通过本地服务保存到 `web\.wrangler` 的本地数据库。它们不再依赖浏览器本地存储；旧版本留下的浏览器数据会在首次成功同步后自动迁移并清理。

因此：

- 使用同一浏览器访问 `http://localhost:3101`，通常会保留即时界面偏好和本地兜底保存点。
- 换浏览器、使用无痕窗口、清理网站数据，可能会清掉这些即时偏好；上面两类已同步的设置不受影响。
- 浏览器里的即时偏好与程序目录里的训练记录、同步设置不是同一份数据。

行情接口凭据、训练会话和后台更新相关的数据由本地服务保存，不放在仓库中。发布包是全新的运行环境，不包含开发者电脑上的个人配置、凭据、训练记录或本地行情数据。

## 备份、升级和迁移

如果你已经积累了训练记录或下载了行情数据，升级前请先关闭控制面板，并备份程序目录中的：

- `web\.wrangler`：本地数据库、训练记录和服务配置
- `web\.local-data`：本地行情数据

浏览器中的即时界面偏好和兜底保存点需要单独在同一个浏览器配置中保留；清除浏览器网站数据不会影响上面两个文件夹，也不会影响已经迁移到本地数据库的两类设置。

正式发布包会自动检查 main 仓库的最新 Release。控制面板发现新版本后，点击“更新到 vX.Y.Z”即可下载并校验更新；更新过程中会自动停止并重启本地服务，同时保留 `web\.wrangler` 和 `web\.local-data`。开发环境和未包含 `release-manifest.json` 的源码启动不会执行软件更新检查。

升级时建议将新版本解压到新的文件夹，确认新版本可以启动后，再按需要迁移备份数据。不要把个人数据文件夹上传到 GitHub，也不要把包含行情接口密钥的目录发给别人。

## 本地服务和端口

控制面板会管理三个本地服务：

| 服务 | 端口 | 用途 |
| --- | ---: | --- |
| 本地数据服务 | `3100` | 读取和初始化本地行情数据 |
| WebUI | `3101` | 浏览器中的训练界面 |
| 后台更新任务 | `3102` | 数据更新和后台任务 |

正常情况下只需要记住 WebUI 地址：<http://localhost:3101>。

## 启动失败怎么办

如果控制面板中的服务显示“未就绪”，先看面板下方日志。常见原因如下：

1. **程序没有完整解压**：重新解压整个 Release 压缩包，不要只复制 exe。
2. **端口被占用**：关闭已经运行的另一份程序或控制面板，然后重新启动。
3. **运行了旧的或不完整的压缩包**：请从 Release 页面重新下载最新版，不要在发布包中执行依赖安装。
4. **安全软件阻止子进程**：确认程序目录完整，并在确认下载来源可靠、文件校验无误后，再根据安全软件提示放行。
5. **本地数据目录异常**：先关闭程序并备份 `web\.wrangler`、`web\.local-data`，再尝试用干净目录启动；不要直接删除唯一的数据副本。

如果日志出现 `Cannot find package 'unzipper'`，通常说明运行的不是完整发布包，或发布包文件被替换/删减。请重新下载并完整解压官方 Release 压缩包。

## 数据源设置（可选）

不配置外部数据源也可以使用内置示例进行训练。需要真实历史数据或增量更新时，再在 WebUI 的数据源设置中填写对应服务商信息。

支持的连接方向包括：

- A 股：BaoStock（默认前复权）、通达信官方不复权日线（支持实时日线更新与权息标记）、TdxQuant（可复权服务）
- 美股：Alpaca 等
- 外汇和现货黄金：Twelve Data、Dukascopy 等

不同服务商的权限、频率限制和数据覆盖范围不同，请以服务商的官方说明为准。接口密钥只应填写在自己的本地环境中，不要写进代码、截图、Issue 或仓库。

## 安全与网络访问

程序主要面向本机使用。默认情况下，数据服务和后台任务只在本机回环地址工作；WebUI 是否能被局域网其他设备访问取决于系统网络和防火墙配置。

除非你明确了解反向代理、身份认证和 HTTPS 配置，否则不要把 WebUI 端口转发到公网，也不要把包含个人训练数据或接口凭据的目录共享出去。程序本身不是带账号系统的公网 SaaS 服务。

## 开发者信息

普通用户不需要阅读本节。若要从源码运行，需要 Node.js 22 或更高版本：

源码调试时，`KLineTrainingCamp.ControlPanel.exe --hidden` 可用于隐藏启动；后台 worker 和本地服务的技术状态只用于开发诊断，不属于普通用户的使用路径。

```powershell
cd web
npm ci
npm run verify
```

生成正式发布包时请传入语义化版本号，例如：

```powershell
powershell -ExecutionPolicy Bypass -File launcher\build-release.ps1 -ReleaseVersion 0.1.4
```

开发时通常需要分别启动本地数据服务和 WebUI：

```powershell
# 终端 1
cd web
npm run local-data

# 终端 2
cd web
npm run dev
```

项目主要目录：

```text
launcher/        Windows 控制面板和便携版打包脚本
web/app/         WebUI、训练流程和服务端 API
web/local-data/  本地行情数据服务
web/public/      静态资源
```

仓库只保留面向用户和协作开发所需的源码、配置模板和发布文件；个人开发记录、内部文档、数据库、行情缓存、日志和密钥不属于发布内容。

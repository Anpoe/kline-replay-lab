# MT4 连接

1. 在训练营「设置 → 基本设置」的训练回收站下方开启「显示 MT4 面板」并保存。从左侧「MT4」进入，点击「准备连接配置」，下载连接 EA 和连接配置。
2. MT4 登录模拟账户，打开「文件 → 打开数据文件夹」，把 KLineTradeBridge.ex4 放入 MQL4/Experts。
3. 在「工具 → 选项 → EA 交易」允许 WebRequest，并添加 http://127.0.0.1。
4. 刷新 MT4 导航器，将 KLineTradeBridge 挂载到一个图表。在「输入参数 → 加载」选择下载的 .set 文件，在「常用」中允许实时自动交易，开启顶部「自动交易」。每个连接只挂载一次。
5. 回到训练营，验证连接、核对账号，再开启模拟交易。从品种列表选择终端行情，输入手数与保护价后，设置订单数后，点击买入或卖出即提交相应订单；网页不再显示二次确认。

连接配置包含本机配对凭证，请保存在自己的电脑上。更换配置时可在训练营重新配对，原配置会失效。若运行文件无法加载，可下载源码，在 MetaEditor 中打开并编译。

若日志出现 MT4 error 5200，请更新连接 EA 并重新挂载。新 EA 通过本机标准 HTTP 入口连接，可继续使用之前下载的配对配置；也可重新下载配置。若页面提示本机连接入口被占用，请先停止其他本机网页服务，再重启训练营控制面板。

实盘默认关闭。以后接实盘账户时，需要在 EA 输入参数中把 InpAllowReal 改为 true，并在训练营核对账号、确认开启实盘交易。切换账户、重启连接或断线后需要重新开启。

看到「待核对」时，请先查看 MT4 的持仓、挂单及账户历史，核对后结束该指令状态；程序不会自动重复发送。暂停交易不会撤销已经到达 MT4 的订单，也不会关闭原有持仓。

报价取自所连接的券商。K 线显示 MT4 服务器时钟，最新一根可能尚未收盘，成交量为 tick 数。历史档案按账户和品种长期保存在本机，自动导入终端已加载的历史，并补取交易附近行情。首次导入前，请在 MT4 账户历史中选择「全部历史」。归档只记录接入后观察到的订单变化，无法还原接入前的修改过程；无法获取的行情会标为缺失，可再次同步或补取。

品种列表来自 MT4 市场报价，最多显示 300 个；找不到时，请先在 MT4 市场报价中加入所需品种。活动订单最多显示 500 笔，超过时页面会提示剩余数量，其余请在 MT4 查看。

终端未连接时，请检查电脑网络、MT4 登录、WebRequest 允许地址与配对配置。连接服务不可用时，请重启训练营控制面板；若仍不可用，请更新程序。历史回放训练不会向 MT4 发送订单。

在现有「历史档案」中选择账户、品种，点击交易行、订单号或开仓/平仓按钮即可在当前图表回看。交易回看时开仓区隐藏，返回实时后可继续交易。绘图、决策和复盘自动保存到本机档案，原浏览器标记会在对应账户归档后迁入，并保留浏览器原记录。当时证据只读，后续复盘单独保存。

通过历史档案中的「备份」下载所有账户的交易、行情、标记与修订记录，通过「恢复」导入到空档案或补回完全一致的记录；存在不同版本时停止并保留当前档案。备份不包含配对凭证。请等待保存完成后关闭页面，未完成的编辑会提供恢复与导出入口。

本包包含独立连接 EA 1.08 与面板合并版 1.15。升级时请先在训练营暂停交易，更新并重新挂载所用 EA，保留原配对配置，验证连接后再开启交易。「全部平仓」会逐笔关闭当前账户的持仓，保留挂单；单笔平仓、撤单和全部平仓均直接提交。关闭「显示 MT4 面板」只隐藏入口并停止网页刷新，原有档案保留；不会关闭持仓或停止 MT4 内的 EA。

在「设置 → MT4 设置」开启「仅显示开收盘波动」，可分别调整每根 K 线开盘后、收盘前的实时波动秒数；两个窗口重叠时持续更新，中间时段冻结图表、指标和浮动盈亏；账户权益、可用保证金及保证金水平按冻结的浮盈显示。首次进入、切换账户/品种/周期或换根时建立一次当前真实行情的显示基线。图表会显示冻结状态，倒计时、报价、持仓变动、交易和历史归档继续实时更新，历史回看不受限制。此设置默认关闭，仅在基本设置启用 MT4 功能后可见。

执行回报不再常驻列表，新提交指令的成交结果通过悬浮通知显示；失败、提交结果未知和待核对时直接提供提示及恢复入口。

网页支持 Buy Limit、Sell Limit、Buy Stop、Sell Stop。选择限价单或突破单，输入或在图表选择触发价，设置订单数（默认 1，每批最多 10 笔）及止损、止盈后提交。网页每笔可分别填写触发价、手数、止损和止盈，均支持图表选价；按账户与品种自动记住订单数、委托类型和逐笔参数，刷新、重启或切换周期后恢复。减少订单数时保留暂时隐藏的行。固定手数按每笔计算，风险百分比为整批余额风险预算，平分到每笔。每笔收到回报并确认订单后继续，遇到拒单、回报不明或账户变化时停止；「停止后续下单」保留已经发送的指令及成功订单。挂单触发价须满足券商方向、最小距离和报价步长要求。

# K线训练营 2.0（本地版）

面向个人交易训练的本地 Web 应用，支持历史 K 线逐根回放、版本化模拟成交、图表标记、训练保存、整体表现统计和确定性复盘。`2026.08-v2` 成交引擎支持市价/限价/止损触发委托、自动止损止盈、手续费/最低佣金/点差/滑点、同根冲突策略和按 K 线成交量参与率部分成交；下单支持固定数量与权益风险百分比仓位。止损/止盈可直接在图表取价并联动事前决策卡，持仓保护线可拖动收紧。单场复盘保存 R、MFE/MAE、期望值、逐 K 权益回撤、连亏、后续路径和证据时间点。训练任务可以指定日期或第 N 根 K 线开始，设置自动结束长度，并选择自由训练、盲测、测试区间或错题重练。顶部有独立随机训练入口，可选择普通随机或盲测随机，并在每局结束后继续随机、查看复盘或退出。“表现”板块可汇总全部训练，并按品种、周期、模式、状态和日期筛选训练集，还会基于不可变快照分析开仓价格、开仓前 20 日平均成交量和成交额区间；市值分析在证券基础资料可用时自动启用。训练仅在手动保存或到达终点时进入可恢复列表，侧栏设置可定义随机训练的品种、市场、周期、历史时段和长度；市场专用随机规则按实际范围显示，美股随机训练还可按训练起点前 20 个交易日平均成交额过滤低流动性品种。不可变行情快照已升级为 v2 内容寻址分块，恢复时可按训练时间窗与左侧历史根数读取，并兼容旧 v1 快照。

当前版本只在本机运行，不包含 Sites 托管、账号或云同步配置。

## 普通用户发布包

从 GitHub Releases 下载 `KLineTrainingCamp-Portable.zip` 并完整解压。发布包已经包含 Node.js 运行时、锁定的 JavaScript 依赖和 WebUI 文件，普通用户不需要安装 Node.js，也不需要执行 `npm install`。请保持 `runtime`、`web` 和 `KLineTrainingCamp.ControlPanel.exe` 的相对位置不变，然后双击根目录中的 EXE。

## 推荐启动方式

双击项目根目录中的原生控制面板：

```text
KLineTrainingCamp.ControlPanel.exe
```

这是唯一的日常启动入口；它是 WinForms 程序，不会额外打开 cmd 或 PowerShell 窗口。控制面板会在后台启动：

- `127.0.0.1:3100` 本机行情与可恢复维护服务；
- `http://localhost:3101` Web 服务；
- `127.0.0.1:3102` 每日自动更新 worker。

面板启动后常驻系统托盘，默认不打开浏览器。点击面板或托盘菜单中的“打开 WebUI”进入：

```text
http://localhost:3101
```

关闭面板窗口只会隐藏到托盘；从托盘选择“退出”会先清理由面板启动的本地服务。勾选“开机后台启动”后，Windows 启动项会直接使用 `KLineTrainingCamp.ControlPanel.exe --hidden`，因此登录时不会闪现面板窗口。旧的 `启动控制面板.bat` 与 `启动本地网页版.bat` 仅保留为兼容转发器。开发者从源码运行时，如果 EXE 缺失，可执行 `launcher/build-native-control-panel.ps1` 构建。

在设置 → 数据源设置中可分别开启“每日启动自动检查更新”和“每日定时检查更新”。定时检查使用运行软件这台机器的系统时间；软件在设定时间之后启动会立即执行，两个开关共享同一天一次的 claim，不会因重新打开 WebUI 或重启面板而重复自动执行。面板的“当前后台工作”和 3102 状态卡会显示 worker 状态；WebUI 只读取和显示任务状态，数据库工作由本机服务端/API 和后台 worker 完成。

网页服务使用 IPv4/IPv6 双栈监听。需要远程访问时，可在启动前自行设置 `KLINE_REMOTE_HOST`；发布包默认不配置固定公网域名，脚本也不会自动开放公网端口。长期公网使用前应增加 HTTPS 和访问认证。

## 本地数据

- 训练记录、小规模导入和不可变训练快照保存在项目本地的开发数据库中。v2 快照按周期分桶、按约 1.25 MB 上限拆块并复用相同内容块；设置中可把训练起点左侧历史窗口配置为 100～5000 根，恢复训练和表现分析只读取需要的分块。
- 数据目录由本地 Cloudflare Miniflare/D1 运行时管理，状态文件位于被忽略的 `.wrangler/` 目录。
- BaoStock A 股数据保存在被忽略的 `.local-data/baostock/` 目录，并生成数据版本清单；不同数据来源的本地目录相互独立，切换来源不会清理已有数据。
- CSV 导入格式：`timestamp,open,high,low,close,volume,turnover`。
- 当前内置 A 股和美股样例行情；“数据”页面首次进入提供快速初始化与高级自定义。A 股默认使用 BaoStock，也可在高级自定义中选择不复权日线或其他复权口径，美股继续使用 Alpaca。
- 快速初始化通过 BaoStock 品种目录识别股票、指数、场内基金和可转债，并获取前复权日线；周线/月线按需由本地日线聚合。初始化和维护都支持暂停、继续与失败重试。无法返回数据的品种会保留为无数据记录，不会静默替换其他来源。
- 全市场初始化按顺序处理，以保持数据一致性。
- 数据页按 A股、美股、外汇、黄金独立管理，不再提供逐个代码下载表单。A股默认使用 BaoStock 前复权日线，并按品种执行增量和缺口修复；也可以选择不复权日线或按数据服务配置复权口径。美股使用 Alpaca SIP 并按最后日期限速更新。账户无 SIP 权限时会明确报错，不静默回退到只覆盖部分成交场所的 IEX，避免同一历史序列在更新中改变数据定义。
- 数据覆盖表支持逐行勾选、全选当前页和二次确认删除；样例数据删除后不会自动恢复，既有不可变训练快照不随行情库删除。
- 各数据来源的维护状态分别保存在本地任务文件中，可暂停、继续和失败重试；权息信息可以单独维护，并在图表中标记相关事件，Alpaca 下载任务仍保存在本地 D1。

### 本地行情凭证

打开应用侧栏“设置 → 数据源设置”，选择需要的数据服务并保存连接信息。BaoStock 已作为内置数据源提供，其他服务在页面中填写对应的连接凭证或服务地址。配置保存在本机，页面只显示连接状态和掩码；保存后无需重启。首次使用时按“数据”页面的初始化引导继续。

`.env.local` 仍作为高级兼容方式保留，对应字段见 `.env.example`。不同数据服务的覆盖范围和复权口径以设置页显示为准。

## 常用命令

```bash
npm run dev         # 启动本地开发版
npm run local-data  # 启动 BaoStock 默认、兼容 TDX/Tushare 的 A 股本地数据服务
npm run build       # 验证生产构建
npm run lint        # 代码检查
npm test            # 构建并运行自动测试
npm run db:generate # 数据结构变化后生成迁移
```

## 当前主要目录

- `app/`：界面、Replay 工作台和本地 API。
- `db/`：本地数据库结构、初始化和样例数据。
- `drizzle/`：数据库迁移。
- `tests/`：自动测试。
- `worker/`：本地全栈运行入口。

# K线训练营 2.0（本地版）

面向个人交易训练的本地 Web 应用，支持历史 K 线逐根回放、模拟交易、图表标记、训练保存和基础复盘。训练任务可以指定日期或第 N 根 K 线开始，设置自动结束长度，并选择自由训练、盲测、测试区间或错题重练。训练仅在手动保存或到达终点时进入可恢复列表，侧栏设置可定义随机训练的品种、市场、周期、历史时段和长度。

当前版本只在本机运行，不包含 Sites 托管、账号或云同步配置。

## 推荐启动方式

双击项目上一级目录中的：

```text
启动本地网页版.bat
```

脚本会检查 Node.js、在首次运行时安装依赖、启动服务并打开：

```text
http://localhost:3000
```

关闭运行窗口或按 `Ctrl+C` 可停止本地服务。

## 命令行启动

环境要求：Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

## 本地数据

- K 线、品种目录和训练记录保存在项目本地的开发数据库中。
- 数据目录由本地 Cloudflare Miniflare/D1 运行时管理，状态文件位于被忽略的 `.wrangler/` 目录。
- CSV 导入格式：`timestamp,open,high,low,close,volume,turnover`。
- 当前内置 A 股和美股样例行情；真实市场数据适配器尚未接入。

## 常用命令

```bash
npm run dev         # 启动本地开发版
npm run build       # 验证生产构建
npm run lint        # 代码检查
npm test            # 构建并运行自动测试
npm run db:generate # 数据结构变化后生成迁移
```

## 当前主要目录

- `app/`：界面、Replay 工作台和本地 API。
- `db/`：本地数据库结构、初始化和样例数据。
- `drizzle/`：数据库迁移。
- `tests/`：自动测试。
- `worker/`：本地全栈运行入口。

产品范围、实现状态和后续规划见上一级目录的 `K线训练营2.0-方案草案.md`。
